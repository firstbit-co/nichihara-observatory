お知らせ・イベント 更新マニュアル

日原天文台サイト|担当者向け

スプレッドシートに1行書いて「公開する」を選ぶだけ。30分ほどでサイトに出ます。
更新シート(右のQRコードからも開けます):
https://docs.google.com/spreadsheets/d/1nUv0VPi4TfoIRrEscgyrEps8zKh50eY8QfI4-gNICyc/

1. お知らせを出す

  1. 更新シートを開き、下のタブ「お知らせ」を選ぶ
  2. 空いている行に、1行1件で書く
  3. 「公開」を 公開する にする(「下書き」の行はサイトに出ません)
  4. 30分ほどしたら、サイトのお知らせ一覧で確認する
公開「公開する」でサイトに出る/「下書き」は出ない
日付2026/11/01 のように書く
種類選んだ種類がそのまま一覧に表示される。臨時休館・臨時開館は「休館・営業」
タイトル一覧に出る見出し
本文自由に。空行を入れると段落が分かれる(セル内の改行は Ctrl+Enter)
重要○ を付けると全ページの上に黄色い帯で出る。急ぎのときだけ

2. イベントを出す

タブ「イベント」に同じように書きます。開催日が過ぎると「これからのイベント」から自動で外れます。

開催日2026/12/14開始・終了19:00 のように(なければ空)
種類観望会/天文現象 などイベント名一覧に出る名前
ひとことで一覧に出る短い説明(必ず書く)
料金「通常の観望料金」「無料」など(なければ空)

3. 直す・消す

  • 直す:その行を書きかえる
  • 一時的に隠す:「公開」を「下書き」にする
  • 消す:行を削除する
  • 重要の帯を消す:「重要」の ○ を消す

4. 出ないときは

  1. 30分以上たっているか確認する
  2. 取り込み結果のページで、その行の「理由」を見る
    https://firstbit-co.github.io/nichihara-observatory/admin/status.html
  3. 理由のとおりに直す → 次の更新(30分以内)で出ます
してはいけないこと:1行目(見出し)を書きかえる/タブの名前(お知らせ・イベント・使い方)を変える。
サイトが読めなくなり、更新が止まります(止まっても公開中のサイトはそのまま残ります)。

わからないときは管理者に連絡してください。
